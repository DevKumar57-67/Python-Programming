# Python Programming Practice Repository

This repository is a collection of Python programs created for learning and practicing core programming concepts, data structures, algorithms, and problem-solving exercises.

## Project Purpose

The goal of this project is to strengthen understanding of:

- Python basics such as variables, input/output, conditions, loops, and functions
- Object-oriented programming concepts
- Arrays, linked lists, queues, and other data structures
- Searching and sorting algorithms
- Problem-solving patterns from coding platforms like CodeChef and LeetCode

## How to Run the Programs

From the project root, run any Python file using:

```bash
python filename.py
```

Example:

```bash
python sum.py
python bubble_sort.py
python linear_search.py
```

## Example Files

- `sum.py` demonstrates adding numbers and user input-based calculations
- `bubble_sort.py` shows the bubble sort algorithm implementation
- `functions.py` covers function definition and usage
- `linked_lists.py` demonstrates linked list traversal and related concepts
- `binary_search.py` and `linear_search.py` are examples of searching algorithms
